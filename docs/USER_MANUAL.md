# User Manual — Student Registration System

คู่มือการใช้งานระบบลงทะเบียนเรียนมหาวิทยาลัย สำหรับนิสิต/นักศึกษา, อาจารย์ผู้สอน และเจ้าหน้าที่ทะเบียน

---

## 1. Student User Guide

### Course Search & Registration (ค้นหาและลงทะเบียนรายวิชา)
1. เข้าสู่ระบบด้วยบัญชีนิสิต (เช่น `student1@reg.edu` / `Password@123`)
2. เข้าสู่หน้า **Course Catalog** (`/student/courses`)
3. ใช้ช่องค้นหาเพื่อค้นหาตามรหัสวิชา, ชื่อวิชา หรือกรองตามภาควิชา
4. ตรวจสอบจำนวนที่นั่งคงเหลือ และเวลาเรียนในแต่ละกลุ่มเรียน (Section)
5. กดปุ่ม **"ลงทะเบียน" (Register)** ในกลุ่มเรียนที่ต้องการ:
   - ระบบจะตรวจสอบการชนกันของตารางเรียน (Schedule Conflict)
   - ตรวจสอบจำนวนหน่วยกิตสะสมสูงสุดในภาคเรียน (ไม่เกิน 22 หน่วยกิต)
   - ตรวจสอบที่นั่งว่างแบบ Concurrency Safe
   - หากสำเร็จ ระบบจะบันทึกสถานะ `REGISTERED` ทันที

### Timetable & Class Schedule (ตารางเรียนและตารางสอน)
1. เข้าสู่หน้า **My Schedule** (`/student/schedule`)
2. ระบบจะแสดงตารางเรียนประจำสัปดาห์ (จันทร์ - อาทิตย์) จัดเรียงตามช่วงเวลาเรียนจริง
3. กดปุ่ม **"พิมพ์ตารางเรียน" (Print Schedule)** เพื่อพิมพ์หรือบันทึกเป็น PDF

### Course Withdrawal / Drop (การถอนรายวิชา)
1. เข้าสู่หน้า **Registered Courses** (`/student/my-courses`)
2. ตรวจสอบรายวิชาที่ลงทะเบียนไว้
3. กดปุ่ม **"ถอนรายวิชา" (Drop Course)** และกดยืนยันในกล่องข้อความ
4. ระบบจะคืนจำนวนที่นั่งว่างกลับสู่กลุ่มเรียนโดยอัตโนมัติ

## 2. Faculty / Teacher User Guide

### Faculty Dashboard (แดชบอร์ดอาจารย์ผู้สอน)
1. เข้าสู่ระบบด้วยบัญชีอาจารย์ (เช่น `teacher1@reg.edu` / `Password@123`)
2. หน้า **Faculty Dashboard** แสดงสรุปจำนวนกลุ่มเรียนที่รับผิดชอบ, จำนวนนิสิตทั้งหมด และคาบเรียนถัดไป

### Teaching Sections & Class Rosters (รายชื่อนิสิตในกลุ่มเรียน)
1. เข้าสู่หน้า **Teaching Courses** (`/teacher/courses`)
2. เลือกกลุ่มเรียนที่ต้องการตรวจสอบ แล้วกดปุ่ม **"ดูรายชื่อนิสิต" (View Roster)**
3. ตรวจสอบรายชื่อนิสิตที่ลงทะเบียนเรียน, รหัสนิสิต, สาขาวิชา, อีเมล และสถานะการลงทะเบียน (`REGISTERED` หรือ `DROPPED`)

### Teaching Timetable (ตารางสอนประจำสัปดาห์)
1. เข้าสู่หน้า **Teaching Schedule** (`/teacher/schedule`)
2. ตรวจสอบตารางสอนรายสัปดาห์ พร้อมระบุห้องเรียนและเวลาบรรยาย

## 3. Academic Administrator Guide

### Semester & Registration Period Setup (กำหนดภาคการศึกษา)
1. เข้าสู่ระบบด้วยบัญชีผู้ดูแลระบบ (`admin@reg.edu` / `Admin@1234`)
2. ไปที่หน้า **Semesters & Periods** (`/admin/semesters`)
3. สร้างปีการศึกษาและภาคเรียนใหม่ พร้อมกำหนดวันเปิด-ปิดการลงทะเบียน
4. สามารถเปิด/ปิดระบบลงทะเบียนเรียนได้ด้วยปุ่มสวิตช์

### Course & Section Management (จัดการหลักสูตรและกลุ่มเรียน)
1. ไปที่หน้า **Course Catalog** (`/admin/courses`) เพื่อเพิ่มรายวิชา, กำหนดรหัสวิชา, หน่วยกิต และภาควิชา
2. ไปที่หน้า **Course Sections** (`/admin/sections`) เพื่อเปิดกลุ่มเรียน กำหนดจำนวนรับสูงสุด (Capacity), อาจารย์ผู้สอน และวัน-เวลาเรียน

### User Account Administration (จัดการบัญชีผู้ใช้งาน)
1. ไปที่หน้า **User Management** (`/admin/users`)
2. เพิ่มผู้ใช้งานใหม่ หรือแก้ไขข้อมูลผู้ใช้งานเดิม (รหัสผ่าน, อีเมล, เบอร์โทร, ชื่อ-นามสกุล, สาขาวิชา และสถานะนิสิต)

### Security & Compliance Audit Logs (ตรวจสอบประวัติการใช้งาน)
1. ไปที่หน้า **Audit Logs** (`/admin/audit-logs`)
2. ตรวจสอบประวัติการทำธุรกรรมทั้งหมด เช่น ใครลงทะเบียนวิชาใด, ใครถอนรายวิชา, ใครแก้ไขข้อมูลผู้ใช้ พร้อมระบุเวลาและ IP Address
